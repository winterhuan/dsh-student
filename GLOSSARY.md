# Student learning

English | [中文](GLOSSARY.zh.md)

Student organizes a learner's study, parent-confirmed material and practice records. These terms distinguish learning activities, published exercises and the learner's own responses.

## Language

**Learner**: The child whose learning activities and evidence Student organizes, continuing across terms. A parent or service login account is separate from this learner.

_Avoid_: Account, term, workspace

**Term**: The period of learning records maintained for one learner, covering their profile, courses, practice and progress.

_Avoid_: Learning block, DSH Session

**Learning block**: A continuous learning activity with a subject, mode and selected scope, which can include several questions. It is distinct from the DSH Session that carries the conversation.

_Avoid_: Session, conversation

**Learning goal**: A specific capability the learner is expected to demonstrate, with applicable scope and criteria for checking the outcome. A textbook chapter or completed activity is separate from this capability.

_Avoid_: Free-text topic, textbook edition, course unit, activity completion

**Capability scope**: The vocabulary set, number range, method, difficulty, or performance modality in which a capability applies. Achievement within one scope is distinct from achievement within a broader scope.

_Avoid_: Mastery state, entire subject, arbitrary same-named goal

**Curriculum association**: A correspondence between a capability and its learning position in a textbook, grade, term, or unit. The association itself does not establish learner mastery.

_Avoid_: Capability identity, response evidence, learning achievement

**Question family**: Questions that assess the same capability using the same core method and problem structure. Changing numbers, characters or wording alone does not create another family.

_Avoid_: Answer format, subject, learning goal

**Source exercise**: The representative question for a question family, with its core method, variation constraints and answer criteria. Concrete questions used in learning are instances of it.

_Avoid_: Question instance, worksheet

**Question instance**: A concrete question presented in a learning activity, with the wording, options and answer criteria used on that occasion. Different instances in one family remain distinct questions in learning history.

_Avoid_: Source exercise, learner response

**Worksheet**: A set of arranged questions prepared for paper practice, with the question content and answer basis.

_Avoid_: Transcription draft, assessment

**Learner response**: The answer the learner gives to a particular question. The question, its answer basis and subsequent feedback are separate from this response.

_Avoid_: Reference answer, model feedback

**Assessment**: The result and feedback for a learner response. Reassessing that same response is a correction, rather than another attempt.

_Avoid_: Learner response, new attempt

**Transcription draft**: Photo-derived question and response text, with proposed interpretations, awaiting parent review.

_Avoid_: Confirmed result, worksheet

**Assistance**: The help the learner uses while answering a question, distinct from whether the answer is correct or the transcription is reliable.

_Avoid_: Transcription confidence, answer correctness

**Answer date**: The calendar day on which the learner actually answers, distinct from the dates of receipt, assessment and correction.

_Avoid_: Receipt date, assessment date

**Mastery baseline**: A previously verified learning outcome used as the starting point for the learner's current progress. It is distinct from newly completed learning or review.

_Avoid_: New attempt, first mastery

**First mastery**: The learner first reaches mastery of a learning goal through response evidence, including verified history from earlier terms. Changing terms does not create another first mastery of the same capability.

_Avoid_: Repeated practice, recovered mastery, inherited mastery baseline

**Recovered mastery**: A previously mastered goal returns to mastery through new learner responses after becoming weak or due for review.

_Avoid_: First mastery, evidence ageing out

**Completed review**: The learner answers a due mistake independently and correctly after it becomes due.

_Avoid_: Attempted review, correctness with help
