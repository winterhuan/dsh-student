# @winterhuan/dsh-student

[English](README.md) | 中文

## 概述

通过当前 DSH 对话、学习工作台快捷键或 `/study` 引导小学生学习语文、数学与英语，跨对话保留原始作答、帮助、反馈和后续练习。家长在聊天中确认设置、学校进度与照片作业；可选手动表单提供另一种保存方式。没有时长限制。包提供精选二年级上册语文和数学课页、一二年级知识地图及已验证参考题；基础材料不建立校内对齐。

## 使用此包

通过[插件市场](https://winterhuan.github.io/dsh-creative/index.json)安装预构建版本，或在 DSH `0.2.2-rc.1` 中安装以下固定 Git 提交：

```sh
dsh plugin --profile market add 'git+https://github.com/winterhuan/dsh-student.git#cbc8409b4d48d210a2df5b4dcfa0b24d58ef3903&path:/packages/winterhuan/student'
```

将 `market` 替换为你已有的 DSH profile 名称。

在新建或空白会话的原生模式菜单中选择**智能学习**，再从右侧栏打开对应工作台。工作台及领域技能、工具只在该模式中可用。已有会话保留原模式；要继续已有项目文件，请在该模式中新建会话。会话状态和项目文件不迁移。全局设置仍可使用。

将已构建的包安装到 DSH `0.2.2-rc.1` 配置，打开独立的学习工作区并调用 `/study`。

```sh
dsh plugin --profile student add ./packages/winterhuan/student
```

配置需要已提供技能、工具、会话文件系统和沙箱策略。web 配置还提供对话、图片附件和学习工作台侧栏。安装层添加 `student` Host 行和 `preset-student` 模式行，不安装任何创作包。安装或重新构建后重启配置。

### 使用学习工作台

在学习工作区的新对话中选择智能学习模式，从右侧栏选择“学习工作台”。工作台分成学生页和家长页。学生页先选语文、数学或英语，显示今日已学时长、今日星数、到期复习和薄弱点数量，并给出一条今日建议（先教需要教学的目标，再补薄弱点，再做到期摸底，再学新知识点）。到期错题收成「今日必清」副卡，最多 2 条，不挡住新内容。主路径可以趣味情境练当前目标，或请助手开互动课。学校进度已确认时，学生页写出当前单元和目标的具体动作。今日页另有「今日学科环节」卡片（按单元侧重与高频错因打印今日小卷或开始对话听写）、「说一遍思路」提醒（可一键「当小老师」费曼讲题，只作提示、不评分），以及当前科目的摸底卡片。开始学习段后，每次展示一道已保存的题目及其学习目标、可选微步骤与西蒙四阶段（demo→guide→try→vary）：题目带图时，图显示在题干旁边；若该目标属于当前学期的知识地图，题旁用三个圆点表示已独立答对的天数。选项题直接点选答案，其他题输入作答。浏览科目仍保留未完成学习；明确切换或结束时，原回答继续保留，供稍后的评估使用。在面板提交回答或请求提示，DSH 对话负责教学与评估。操作随题目状态显示为出题、重新请求反馈或提示、下一题，均沿用当前学习段。收到反馈后仍保留原回答。帮助、来源、实际作答日期、题目依据或学习目标尚未核实时，记录明确显示为待核对。一键「结束本段」即可停止；复述可选，也可通过「当小老师」对话自然完成。工作台分别报告原生消息接收与独立核实的已保存回答、评估。接收结果不确定时，可明确检查且不会自动重发；模型错误仍显示在对话中。

家长页分为三处。「待办与练习记录」包含未完成学习、错题转录、到期复习、错题本、习题与练习单。「知识与进度」包含概念关系、知识地图和三科摸底；浏览其他册保留已选学习范围与当前学习段。「档案与小结」先提供对话更新档案、课程与归档的操作，再显示本周进度、星星和近期证据。可选表单通过应用的类型化接口保存档案、课程及学校进度。已保存练习记录另有补充修订表单，分别修改评估、错因、作答帮助与家长确认的实际作答日期；整张练习单的实际作答日期用于未单独填写日期的回答；逐题日期与明确的待核对覆盖值保持不变。原回答与冻结题目依据始终可见。草稿按原生会话、学期与编辑实体保存，切换页面和无关刷新后仍保留。保存使用当前已观察文件版本；相关冲突保留草稿并显示当前值，可明确采用当前值或保留已核对的草稿；旧学期草稿不能改变当前学期。默认练习、转录确认和归档操作向原生对话提交完整意图。纸面转录置信度与正确性、帮助分别保留；只有高置信、明确答对、已知帮助且没有不确定信息的草稿提供批量确认。待确认、到期和近期作答列表最多展示 20 条；更早记录可在对话中查询。

### 打开互动课

本机已经在运行 OpenMAIC 时，今日建议旁可以对当前目标一键生成互动课。requirement 写入已保存的兴趣标签和已确认的校内单元，例如欢乐购物街。生成中显示状态；可以上课后，「去上课」放在今日页上方。今日学习也列出最近的互动课，并可在浏览器打开课堂链接。生成、大约一分钟一次的轮询、重试和课后大纲由学习助手用 curl 和同一个 cookie 完成，因为 web_fetch 访问不了 localhost。对话里的课堂 URL 是单独一行的裸地址。课后助手保存一段短大纲，并按现有练习回路出 2 到 5 道巩固题。家长设置可以保存 OpenMAIC 地址。保存过的地址优先；否则使用环境变量 OPENMAIC_BASE，该变量也没有时用 `http://localhost:3000`。服务若要求访问码，从 OPENMAIC_ACCESS_CODE 读取，不写入学习档案。工作台不嵌课堂页面。

### 选择学习方式

智能学习是会话模式。在学习工作台的「换一种方式」里选择科目和以下四种学习活动，没有共用的每日时长预算。自主探究可填写「我的疑问」。同步学习按该科是否已确认学校进度，记成校内同步或标明来源的通用基础。工作台保存题目与回答，对话承担讲解、提示和辅导反馈。

| 学习活动 | 适合什么时候使用 | 前提 |
|---|---|---|
| 同步学习 | 按已确认的学校单元练习；还没确认教材时，作为标明来源的通用基础练习 | 家长已确认学习档案 |
| 错题复习 | 回忆已确认的错题，或尝试相关变式 | 所选科目有已确认且到期的错题 |
| 摸底检测 | 按知识地图抽样做几道短题，找出已经会的和要再练的知识点；分轻量、常规、全面三档 | 已有学习档案；每科 14 天建议一次，可随时重做 |
| 自主探究 | 围绕孩子的问题，进行猜想、观察和解释 | 已有学习档案；在对话中说明想探究的问题 |

首次使用先在家长页完成家长设置。今日学习显示所选科目的方法、今日已学时长、今日星数和到期复习数量。家长可核对并修改助手提出的概念定义、例子和依据，再确认概念；助手据此建立可选择的学习目标及有依据的前置、组成、对比、解释或因果关系。选择一个目标后，用同步学习开始。旧错题保留原 `topic`，由用户核对后关联目标，不自动猜配。在错题巩固中选择到期复习，再由用户在今日学习明确开始；agent 明确结束或切换学习块并保留待办。提交回答后等待反馈，「结束本段」结束本段。

错题本可以打印每日小卷、练习卷和巩固卷：每日小卷 4 到 6 题，按当天学科环节出题（生字或单词、句子或口算，再挑一个反复出现的错因出变式）。练习卷覆盖当前学校单元，一张卷里可以有这个单元的几类题，题型会换开，孩子在纸上写答案。巩固卷由系统挑错题：当天或明天到期、复习阶段最低的最多 8 条，每条一道变式，已经印在还没批改的卷上的错题不会重复挑。练习单渲染为网页：家长在工作台预览整张卷，再经浏览器打印对话框选择打印机或「存储为 PDF」，Windows 同样可打印。卷面能画线段图、人民币、十位个位点子图和计数器、百数表（含九格局部窗口）、数轴、钟面（整时、半时和几时几分）、小棒、竖式格、图形比较、平面与立体图形辨认、重叠圈（和圈与集合图）、数的分与合、规律条、数墙、方格表、点子方阵、厘米尺、方向板、天平、田字格、四线格，画不出的图形用简笔画兜底，每题留一行、三行或一个方框的作答区，屏幕上的题图与打印出的题图是同一套。卷面只有题目、图和作答空间，答案依据留在学习记录中。

孩子做完后，家长在错题本展开这张卷，对照参考答案逐题点对、半对或错，答错时可以填上孩子写的答案并选错因，再保存批改；也可以把卷面照片发给助手：助手逐题保存转录草稿，家长通过聊天或可选手动表单核对确认后入库。练习卷上答错或半对的题记入该题学习目标的错题；改判为对时这条错题随之删除。每条巩固题按复习阶段变换式：先换数字、再换情境、再到说理，并保留原错因。巩固卷上的题按天计算：独立答对在任何一天都进入下一阶段，下次复习日从做对那天起算；答错或半对只回到第二天，阶段不倒退。不再用的卷可以作废，卷上的错题随后能重新出题。纸上结果不用开启计时学习段，也不发星。

若已启用 DSH 的 SenseVoice 语音输入，可用对话麦克风口述答案。转写文字先进入对话草稿，学生核对并发送后，助手按当前题目保存原回答。转写文本不能用来评价朗读或英语发音；工作台没有第二套录音控件。

### 确认学生与资料

每个工作区在格式 2 正式文件中保存一名学生的一学期。原生对话是设置与管理的默认入口；家长确认昵称、地区、年级、学期、学年、学制、兴趣和可选课程备注。未知学年等待实际确认。档案编辑保留历史学习上下文；教材与学校进度共用一次设置写入。基本档案确认后可先做基础练习，再完成校内关联。归档保留原学期身份与来源；新学期使用新身份。旧来源可读取，新的正式文件工作需先明确迁移。

逐科确认书名、出版社、版次、封面或版权页依据以及当前单元。确认教材后，再在家长设置里选择学校现在教到的地图单元：新课和摸底停在这个单元以及已经教过的单元，可以选跟上学校或先补缺，复习周不开始新目标，预习最多提前一个单元。进度只在确认后前移。校内同步要求版次已识别、课程范围匹配并记录家长确认。课程未确认时可进行明确标注的基础练习。教材改版使用独立资料 ID，先前作答保留原资料引用。官方入口和来源规则见[教材资料](knowledge/skills/study/references/materials.md)。

<a id="use-default-textbooks"></a>
### 使用默认教材

二年级上册未提供某科教材时，`/study` 使用随包提供的人教社语文或北师大版数学，用户提供的教材和课页优先。无需再次上传这两本书；完成档案设置后选择“通用基础”，或在对话中说“用默认数学教材学习乘法”。尚未指定学习主题时从第一单元提供短小选择。默认教材不代表学校采用版本，也不自动填写校内进度；英语和其他年级、学期没有默认教材。

教材目录、版本依据和读取规则见[默认教材](knowledge/skills/study/references/default-textbooks.md)。课页通过 DSH 的 `read_image` 按需读取，需要支持图片的模型；文字层仅供检索定位，不能直接用于拼音、图形或竖式判分。缺少图片能力时使用用户提供或已核对的题干，或明确标注的自编基础练习。

<a id="use-the-knowledge-map"></a>
### 使用知识地图与薄弱点

插件内置一、二年级上下册的语文、数学、英语知识地图，共十二份，依据《义务教育课程标准（2022年版）》第一学段整理。语文和英语的一年级上下册、二年级上册按家长确认的教材目录列出单元和课名；数学这三册对齐沪教版五四制 2024 年相应册次目录。三科的二年级下册仍用先前的学习框架。它是学习框架，不代替学校课本和教师进度。地图里的学习目标无需家长确认即可用于出题、作答、错题归类和练习单；助手用 `study_status kind=curriculum` 读取知识点定义、例子和可考事实后出题，并在每道题上记录学习目标。十二份地图的每个知识点都有可考事实，题目不得超出这些事实。二年级上册语文整理自随包人教课页。语文一年级上册和一年级下册里，读到统编版（2024）课页并且正文清楚的知识点，已改成课文原句、生字和笔顺；《1 a o e》和《2 i u ü》仍是原来的事实。语文二年级下册仍按这一课可以核对的内容整理。英语二年级上册 Unit 1 到 Unit 4 对照家长朗读纸；该册 Unit 5 到 Unit 10、一年级上册 Unit 1 到 Unit 6 与 Unit 8 到 Unit 10、一年级下册 Unit 1 到 Unit 10 写入了读到的 2024 沪教五四制原句。一年级上册 Unit 7 只有对得上的句子改过。Starter、两册附录和二年级下册仍是话题词的意思。数学一年级上册、一年级下册和二年级上册里，读到课页或教案并且概念对得上的知识点，已改成这些页面上的算法、口诀和图形特征；没有对上的知识点仍是原来的事实。数学二年级下册这次没有改。读到概念对得上的课页或试卷后可以改这些事实。出版社和册次可以不同。试卷题目是课程佐证，新题另写，不照抄原题。

掌握状态由实际记录推导：三个不同日期独立答对、没有未完成复习的错题且近期没有依赖帮助或答错显示为已掌握，地图的知识点详情与学习目标行、答题页都用三个圆点显示已独立的日期数，第三天答对时工作台祝贺一次；最近 14 天两次以上答错或依赖提示、或有两条以上未完成复习的错题显示为需要加强；练过但超过 10 天没练显示为久未练习；有到期错题显示为待复习。需要教学的目标会沿知识地图的前置关系回溯，先补最靠近的未掌握前置目标，掌握后再回到原目标。薄弱点按到期错题、最近出错和久未练习排序，同一错因反复出现会提高该目标的优先级；今日建议依次为需要教学的目标、薄弱点、到期摸底、新知识点；到期错题最多清 2 条。今日页的「说一遍思路」提醒由当天证据派生，只作提示，不计入掌握。这些状态描述证据，不是能力标签，也不替代学校评价。地图范围、查询方式和巩固回路见[知识地图](knowledge/skills/study/references/knowledge-map.md)。

摸底检测是重复进行的短摸底：每科把未探查、久未练习和已掌握超过 35 天的目标按单元轮流取样，距上次摸底满 14 天时建议再做一次，也可随时重做。强度分三档：轻量 3 题（全部选择题）、常规 6 题（默认）、全面最多 12 题（每单元至少一道说理题，并复测练习中的目标），工作台按未探查数量推荐一档；内置习题库可为抽样目标附带推荐摸底母题。摸底段里每个目标一道短题，作答必须关联学习目标；从未独立答对的目标只要答错一次就标为需要加强，今日建议随即转向针对性练习。摸底不计分、不排名，也没有时长截止。

### 学习与复习

辅导者开启一个学习段，提出简短问题，等待学生并记录真实回答与帮助程度。没有单段、休息或每日分钟限制；孩子累了可以随时停止，不扣星、不责备、不补打卡。时长是包含等待的钟表时间，停止时按实际经过时间记录。日期使用上海时区。不安装后台闹钟或屏幕锁。作答匹配、选项归一与摸底强度见[软提醒决策](https://github.com/winterhuan/dsh-creative/blob/upstream-conventions/.agents/notes/implemented/bug-fix/2026-10-18-student-soft-time.zh.md)；取消时长限制见[全面改造决策](https://github.com/winterhuan/dsh-creative/blob/upstream-conventions/.agents/notes/implemented/feature/2026-10-30-student-overhaul.zh.md)。

每天实际作答最多获得一颗参与星，学生复述可再得一颗。挂机、多刷题、延长学习和连续天数均不额外加星。进度报告展示证据和主题，不排名，也不当作考试成绩。

图片错题由辅导者通过 DSH 读取，保存转录和疑点，再请用户确认修正后的题干与答案依据。所有新错题确认前都处于待核对状态。确认后的第二天起算到期；独立答对在任何一天（提前也算）都使间隔依次延长到 1、7、16、35 天，同一天最多进一阶段；依赖帮助或答错只回到第二天，阶段不倒退。复习进度由全部作答记录推算，改判或补录后会重新计算。不同三天的独立答对仅作为进展证据，不等于永久掌握。家长也可通过对话录入、编辑或删除已确认错题，并把题目收入工作区习题库供后续变式参考。

可以请 `/study` 查看进度、继续到期错题或探究孩子的问题。探究围绕孩子输入的疑问，采用小型预测、观察和解释过程。可选的每日提醒仅在家长指定时间后使用 DSH 当前可用的提醒工具，本包不自动创建提醒。

## 理解实现

职责与信任边界见[学生学习子系统](https://github.com/winterhuan/dsh-creative/blob/upstream-conventions/docs/subsystems/student.zh.md)。在仓库根目录通过 `pnpm --filter @winterhuan/dsh-student build` 构建，通过 `pnpm --filter @winterhuan/dsh-student test` 测试。

Host 入口负责已验证工作区读取、类型化手动保存和配置。`./agent` 导出在 `student` preset 及继承它的原生子 Agent 组合内注册领域技能和工具。preset 提供任务专属 persona 和显式原生工具组合，不改变默认模式。学习模式使用文件、搜索、网页、提问、呈现和系统对应的 shell 工具，不默认挂载委派或创作生产工作流。

<summary>实现细节——点击展开</summary>

[配置补丁](cordis.patch.yml)加载[宿主插件](src/index.ts)。[知识地图加载器](src/curriculum.ts)读取并校验 `knowledge/curriculum/` 里的十二份地图与 `knowledge/curriculum/exercises/` 习题库，状态文件只保存目标引用。[学习状态更新器](src/learning/update/index.ts)检查课程、概念关联、奖励与复习转换，用地图校验内置目标引用，并从作答、纸上结果和错题阶段推导掌握状态、薄弱点与每日建议；[状态定义](src/schema.ts)校验模型输入和持久化数据，并迁移去掉已删除的时长字段。新增集合有默认空值，旧档案读取时不猜测概念关联。面板和工具共用持久化的题目、已提交答案、提示请求、纸上结果与工作区习题；辅导评分必须对应已保存题目和学生原始回答。示范保留在教学内容里。已发布练习单冻结每题的内容、目标与历史背景；来源错题更改或删除不影响练习单使用，替换卷面需要新身份。练习册照片核对后保留原答案和结果，不把接收时间当成实际作答日期。原生工具参数由同一输入定义投影生成。DSH 的常规工具日志记录调用和结果。

[正式文件接口](src/files/index.ts)通过 `./files` 导出，让应用读取、类型化手动保存与只读 Node 消费者共用严格定义和业务校验。格式 2 在 `.study/settings.json` 保存学期设置，在 `.study/blocks/<blockId>.json` 为每个学习段保存一份文件，在 `.study/worksheets/<worksheetId>.json` 为每张练习单保存一份文件，在 `.study/collections.json` 保存其余有上限的集合；OpenMAIC 保留独立校验的 `.study/openmaic-lessons.json`。读取检查目录成员与实际文件版本，最多尝试三次。已校验文件、备份及查询缓存归应用 Host 所有，并在其释放时清空；只读适配器保留各自缓存。证据与工作台缓存归各自的投影状态所有。无效实体暂停相关保存。无关文件无效时，设置与教材查询明确返回部分结果；证据不完整时暂停小结投影。应用在 `.study/backups/` 为每个实体保留最多三个已观察的有效版本，总计不超过 128 份备份和 32 MiB 源字节。同一个 Host 所有者按设置文件的实际目标串行执行完整备份保留操作；没有该所有者的自定义文件适配器仅保证顺序保留。备份发现、读取、清理与写入失败分别报告，不阻止有效业务数据的读取或保存。恢复描述要求明确选择并保留无效原件。工作台通过注册时声明的 store 在渲染前恢复草稿，组件使用普通回调调用宿主；手动保存检查学期身份、编辑字段基线和当前文件版本。档案保存将选定编辑字段与当前未编辑值合并；教材与学校进度共用一次设置写入。校验原始字节的 v1 迁移与归档描述逐项提供输出和缺失来源事实，不写入或修复业务文件。正式文件每份最多 8 MiB，活动学期总计最多 32 MiB，包含最多 5,000 个学习段、500 张练习单与 128 个归档学期目录。旧 `.study/state.json` 可读取且不改变原字节；评分时间、接收时间与默认独立作答不会成为已核实的学习证据。已验证迁移备份标明所需输出；缺少文件时工作区保持 migration-incomplete，完成前不提供当前事实。

### 演练恢复

构建后，使用已安装的 DSH `0.2.2-rc.1` 可执行文件和仓库外证据目录运行真实原生工具恢复测试：

```sh
DSH_BIN=/absolute/path/to/dsh STUDENT_EVIDENCE_DIR=/path/to/evidence pnpm run test:recovery
```

测试使用隔离临时 Home、Agents 和 Documents 目录，再等待子进程清理。它通过真实原生 write/edit、构建 CLI 和独立消费方覆盖合成 v1 来源保留、中断迁移及来源变化拒绝、有界已观察备份、明确恢复、部分归档、新学期拒绝与重启。它不在独立恢复工作区运行旧插件，也不建立浏览器、固定 Git、真实教学、OCR、课堂或物理打印验收。

### 校验原生文件编辑

构建本仓库后，运行随包发布的同一可执行文件：

```sh
node packages/winterhuan/student/lib/cli.js --help
node packages/winterhuan/student/lib/cli.js schema term-settings
node packages/winterhuan/student/lib/cli.js example figure
node packages/winterhuan/student/lib/cli.js validate --workspace /path/to/workspace
```

安装后使用 `<study 技能 Base directory>/../../../lib/cli.js`；`./cli` 导出与 `study-validate` bin 指向同一文件。DSH Git 安装不承诺全局 PATH 命令。校验读取正式文件与完整独立课程日志，保留字节/修订，不创建备份或修复。退出 0 指明观察到的 kind、身份和版本；非零 JSON 指明路径、字段、规则和修正方式。校验输出最多 32 KiB，并明确遗漏。schema/example 从源定义生成完整资源；跨文件和来源事实检查仍由 CLI 执行。CLI 未独立匹配 Host 接收版本时，原生作答日期保持未知。部分操作和明确恢复见[编辑参考](knowledge/skills/study/references/files.md)。

内置目标的新题默认使用保存的历史档案年级与学期；跨册时必须由 `context.scope` 明确选择匹配的知识地图，浏览本身不授予范围。只有摸底学习段可记录强度，摸底题不带教学阶段。复习题绑定同科同目标的已确认错题。准备的错题巩固题须更换原题面；练习册记录保留原题面。旧题保留未核实事实，已观察使用内容在来源错题更改或删除后保留冻结绑定。

[Student Remote](src/remote-service.ts)为已注册的 DSH 主会话提供生成的类型化查询、显式手动保存与提交检查。Gateway 在每次调用前检查会话权限；缺失、已关闭和子 Agent 会被拒绝，且不触发激活。提交检查分别报告原生消息接纳、已保存原答与有效的已保存评分，绝不重发输入。手动保存使用已观察的学期、版本和编辑字段基线；设置明确提供 `editedProfileFields`。Host 配置默认 `refreshIntervalMs: 3000`、`maxWireBytes: 1048576`，限制完整请求与响应的 JSON 大小，包含 watch/manual/inspection 包装；超大的手动请求在保存前拒绝。[客户端资源提供者](src/client/resource.ts)通过原生重连跟踪 `dsh-resource://student/session/<encoded-id>?query=<encoded-JSON>`，在失败时报告错误并将之前的值标记为过期状态，等待流关闭后才撤销命名空间。

[原生来源读取器](src/transport.ts)仅观察发起调用的已授权会话。较早会话的原始回答和文件时间戳保持完整，但没有单独授权的来源观察时，投影日期仍为未知，也不计入有实际日期的独立作答证据。完整原始事件重放最多读取 100,000 个事件和 16 MiB；原生传输视图最多 32 KiB，包含 20 条已消费输入、20 条接纳记录，每条输入最多 2,000 个文本字符和八个附件引用，并明确省略的输入、接纳记录和附件数量。历史不完整或存在不支持的事件时，接收来源事实不可用。接收版本匹配已消费输入的完整来源与内容，包括附件；稍后的消费、文件写入和评分不会生成作答接收时间。

练习单由[客户端试卷视图](src/client/worksheet-view.tsx)渲染，与屏上题图共用同一套 SVG 图形；打印走浏览器打印对话框（可选择打印机或存储为 PDF），Host 不生成 PDF，也不调用系统打印队列。客户端通过原生会话队列提交辅导请求，不替换输入框草稿。

默认教材资源位于技能的 `textbooks/`，随 `knowledge` 打包。目录、逐页图片和未校对文字由[教材准备脚本](scripts/prepare-textbooks.py)从两份已核对的 PDF 生成；脚本使用 PyMuPDF 1.28.2 并在写入前校验源文件哈希。运行时使用原生文件和图片工具，无需 Python、PDF 解析器或原始下载路径。教材选择由技能指引，不自动修改学习状态；默认教材作答的页码和依据保存在 `answerEvidence`。

## 模型体验

### 学习指引与记录

#### 模型看到的内容

所选模式加入领域 persona 和一个只读 Student 工具 schema。[提示词快照](../../../tests/fixtures/student-persona.txt)记录前缀；标准与其他领域模式不包含这些能力。非 Web 环境保留 `/study`。`study_status` 读取有效文件和有上限的教学上下文：实际版本、当前学习段/题目、原回答、待评价状态、合法动作、选定范围、目标事实/来源/方法、提示阶梯和至多三道母题。文件目录和版本分页或明确遗漏；过大记录指向原生文件读取。助手用原生文件工具编辑所有业务变化，运行随包 CLI，并区分消息接收、回答保存和有效评价保存。源定义生成的 schema 与示例按需加载，包含全部 23 种图形。技能覆盖设置、教材、教学、照片、练习单、恢复和 OpenMAIC。原生 shell 请求使用独立的同源 cookie jar；认证内容保留在模型可见业务文件之外。原生压缩管理累积历史。参数 JSON 大小是字符数；完整请求/调用记录与单独标明的密度估算不能证明提供商 token、图片成本、教学质量或费用。

#### Token 影响

技能正文和参考按需加载，启用时提供一个只读 Student 工具定义；每次请求也包含原生工具的成本。集合查询每页返回 20 条及下一页偏移。不加载整本教材。尚未测量真实模型的 token 或教学质量基准。

#### KV Cache 影响

插件使用常规 DSH 技能与工具历史，不改写已有消息，也不创建其他模型会话。

## 已知限制与待办

<a id="known-limitations-and-deferred-work"></a>

- 数学一年级上下册和二年级上册的单元与知识点对齐沪教版五四制 2024 年目录，仍不是逐页课本。语文和英语的这三册按家长确认的目录列出课文和栏目，也不是逐页课本。三科二年级下册仍用先前的学习框架，可能与学校课本不同。掌握状态只统计带学习目标的记录，旧作答没有目标就不进入薄弱点分析。摸底一次最多探查六个目标，取样跨单元但不是全面测评；摸底题由模型按目标出题，有可考事实时答案不得超出这些事实，题目质量仍需家长留意。
- 插件不认证家长身份、不测量注意力、不保证 AI 答案，也不提供完整的上海课程库。确认记录用户陈述，来源分类本身不能证明正确。实际教材、学校进度和争议答案仍需人工核对。
- 图片录入依赖支持视觉的 DSH 模型与可读附件。本包没有独立 OCR 服务、教材下载器或自动提醒。图片路径引用提供的附件，不将图片字节复制进状态文件。语音输入依赖另行启用的 DSH Bundle，转写不验证发音。
- 打印经浏览器打印对话框完成，可选实体打印机或「存储为 PDF」；实际纸张输出与浏览器打印状态由家长自行核对，本包不提供打印队列回执。
- 记录的学习操作没有时长限制；插件仍不能锁定操作系统或任意聊天。应用保存检查已观察版本，原生与 shell 写入不受此检查约束。已观察备份不能恢复未曾读取就被覆盖的历史，迁移与归档逐份写入文件。
- 状态保存在本地，但辅导用到的片段和图片会传给配置的模型提供方。插件不是离线或加密的学习资料库。原生工具和文件系统测试不能证明真实模型的识图准确率或教学效果。

- 互动课需要本包不安装、也不启动的 OpenMAIC 服务。Host 不调用该服务。学期归档不会清掉课表，文件留在工作区里，直到有人删除。
- 转录、变式题和每日小卷由模型生成；卷面照片先保存为转录草稿，家长通过聊天或可选手动表单确认后才进入记录和复习，纸面练习仍是主要学习形式。
