# Student 能力目标重建稿

[English](README.md) | 中文

## Summary

这份数据稿把一、二年级三科的课程目录转换为可检验的能力结构，并给旧目标和旧题保留去向。每项能力有范围、判据、先修和母题关联。Student 通过能力与母题查询读取随包运行副本。旧课程地图继续提供教材位置和历史引用；学习记录沿用格式2。

本次从教育部三科课程标准原文提炼能力，再逐条核对随包课程与题库。结果为语文32项、数学42项、英语17项能力及123类母题。这是本稿分解后的统计，涵盖确认后才启用的教材扩展，不是规定孩子必须依次完成91项任务的课程表。

## 目标怎样确定

能力身份按“能做什么”确定。教材、年级、学期、单元、词字集合、数域和难度是适用范围；新学、补学和复习是用途。同一能力跨学期延续，不按一篇课文、一道数字题或一个课堂再复制目标。范围扩大时，只继承已核实且兼容的部分。

[能力与母题数据](catalog.json)是本稿的内容来源。每项记录含 `scope`、`criterion`、`sourceLocators`、`prerequisites`、`familyIds`、`curriculumAssociationIds` 和证据要求。先修表示所选母题需要的相关范围，不要求先把整个上游能力标成掌握才能学下一项；孩子已有合格证据时直接使用。

语文认字与写字、数学加法与减法/验算、英语听与说/读与写分别检验。一个目标内的字词、数域和方法覆盖也分别记录；一道题正确不能授予整张词表、整个数域或全部方法的掌握。答题能力沿用三个不同实际作答日独立正确及错误/帮助/错题条件；阅读习惯、活动参与和长期阅读量保留观察与活动记录，不用一次题分冒充。

<a id="learning-path"></a>

## 孩子的学习主线

起点是家长确认范围内的当前能力缺口。系统选择一个目标和适用母题，再让 OpenMAIC 生成课堂；母题为教学和检验提供方法与结构。孩子先看到“今天学什么”和一个下一步，不需要先浏览目标树或母题库。

例如，确认20以内进位加法后，当前任务可以是“把8+7先凑成10”。课堂后的真实回答和方法证据决定下一步：有效证据足够就安排再练；需要帮助则补讲同一母题，再给新数字变式。8+7、9+6和8+6不增加题库条目。当前活动与先修补缺优先，随后最多两个母题的到期短复习，再进入校内新目标。

| 旧内容 | 重建结果 | 继承条件 |
| --- | --- | --- |
| 整单元、附录、综合复习 | 保留课程/资源关联；不是独立能力掌握。 | 按原题与可分离子问映射，整单元总分不授予所有候选能力。 |
| 混合能力目标 | 分别关联实际检验能力。 | 如竖式减法与加法验算分别评分，不从一个总分推断两项均会。 |
| 同一能力的旧目标 | 跨学期合并为稳定能力身份。 | 只继承相同或更小范围的有效证据，原回答不复制。 |
| 同型数字、人物或情境题 | 关联一个母题；原题面成为历史实例。 | 保留原输入、原评分、有效评分、日期、帮助及来源。 |
| 只有规则描述、选择或不完整来源 | 保留诊断、部分能力或待核对记录。 | 不授予未观察到的实际操作、听说或阅读能力；用新检验补缺。 |

例如，`ex-m2a-sub-1` 的“52−28并验算”分别关联减法与检验；“破十或想加算减”只关联实际展示的方法。英语“怎么说”按真实回答形式分流：文字只支持已确认的书面范围，有声音或可信观察才能进入口语；同一次回答不复制成两次学习。

四道旧题只保留诊断：三道附录使用规则题，以及缺英语阅读材料的颜色回忆题。其他118道具有附带证据条件的候选去向，不表示它们的历史回答已合格。缺原文、实际声音、操作作品、可分离评价、日期或帮助时，相关条件保持未知。

## 来源与覆盖缺口

[来源与覆盖矩阵](sources.json)记录三份教育部原文的地址、校验摘要、PDF页码、24组要求及对应能力。判据是本方案的检验分解，不能当作教育部原文逐字规定。课程标准给出学段要求，教材和学校进度决定实际开课顺序。

| 原文核对结果 | 目录处理 |
| --- | --- |
| 数学第一学段认、读、写与比较万以内的数；旧库最多到千以内。 | 数域覆盖增加到万以内；旧千以内证据不能证明万以内。 |
| 数学第一学段包括除法、拼图与立体的面、时分秒、分类记录及实践交流。 | 补出能力，不因旧目标/题库缺项省略。 |
| 克、千克在国家课标第二学段综合实践；旧二下框架已包含它们。 | 保留教材扩展，确认后启用；不称所有一二年级必学。 |
| 数墙、幻方是旧教材扩展；线段的单独认识也需核对教材。 | 与一般变化规律/测量能力区分，依教材确认。 |
| 语文要求拼音书写、字母表、标点使用、材料梳理与提问探究。 | 补出目标；认写字量、诗文和阅读量分别记录，不拆成几千个目标。 |
| 英语预备级以视听说、游戏与角色扮演为主。 | 听词、指令、故事、声音模仿、口语和视听分别检验；读写及故事口述扩展需教材确认。 |

13项能力在旧目标索引中尚无课程关联，包括除法、图形拼组、时分秒、数据记录、数学活动表达、拼音字母表、标点、提问探究、英语听故事/视听及独立写词。它们已有候选定义和检验设计，具体教材单元和要求仍待对齐。其余关联也只表示旧课程位置，不等于本轮完整核验了教材全部课页。三科二年级下册尤其需要补教材核对。

## 分步改造与验证

随包目录提供判据、先修、母题和附带证据条件的旧 ID 去向。共享校验核对学生身份、母题关联及实际检验范围；只读迁移描述保留原回答和待核对事实。后续按下面的依赖顺序推进；完整融合设计由[学习闭环提案](https://github.com/winterhuan/dsh-creative/issues/58)维护。

1. 对齐教材和学校范围，逐项处理上述课程关联缺口；在隔离副本枚举工作区自定义目标、题库及真实旧回答。
2. 完成证据级迁移演练，校验旧 ID 别名、跨学期引用、同型归并、未知事实及重复迁移，核对原历史保留。
3. 接入官方课堂生成身份、自动登录续登与真实作答读取；让导入消费本目录的实例、母题和评分判据。
4. 简化为学习/家长入口，串通课堂、核对保存、必要补缺、按日复习及下一目标，再做真实 DSH 验收。

在 Student 子模块运行以下命令，检查数据结构、双向关联、先修环、旧目标/题目覆盖、来源页码、原题面与来源文件摘要。自检同时验证拒绝成环、重复母题、漏旧目标、无条件授予掌握和无效引用。检查不会读写日常学习记录。

```sh
python3 docs/capability-rebuild/verify.py --self-test
```

修改能力数据后，用下面命令生成随包运行副本和两种语言的表格，再重新记录文档配对；校验器只替换页面生成标记内的内容。

```sh
python3 docs/capability-rebuild/verify.py --write-preview --write-runtime
```
