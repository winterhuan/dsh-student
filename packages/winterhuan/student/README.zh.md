# @winterhuan/dsh-student

[English](README.md) | 中文

## 概述

通过当前 DSH 对话、学习工作台快捷键或 `/study` 引导小学生学习语文、数学与英语，跨对话保留原始作答、帮助、反馈和后续练习。家长在聊天中确认设置、学校进度与照片作业；可选手动表单提供另一种保存方式。没有时长限制。包提供精选二年级上册语文和数学课页、一二年级知识地图及已验证参考题；基础材料不建立校内对齐。

## 使用此包

通过[插件市场](https://winterhuan.github.io/dsh-creative/index.json)安装预构建版本，或在 DSH `0.2.2-rc.5` 中安装以下固定 Git 提交：

```sh
dsh plugin --profile market add 'git+https://github.com/winterhuan/dsh-student.git#v0.2.8&path:/packages/winterhuan/student'
```

将 `market` 替换为你已有的 DSH profile 名称。

在左侧栏选择孩子的学习工作区，打开已有对话或新建使用**智能学习**模式的对话。**学习工作台**会自动展开，与 DSH 原生辅导对话并排显示，提供「今日学习」「知识进度」「练习批改」「课堂记录」「学习档案」直接入口；关闭后也可从右侧栏重新打开。工作区和对话由 DSH 管理。每个工作区保留一名学生的一学期记录，在其中切换对话会共用这些记录，关闭侧栏或切换对话时保留草稿。没有档案时提供原生对话建档入口。旧版档案仍可浏览和预览打印练习单；保存新的学习数据前，先让助手检查迁移方案，再由家长确认。

领域技能和工具仅在智能学习模式中可用。已有会话保留原模式，会话状态和项目文件不迁移。

将已构建的包安装到 DSH `0.2.2-rc.5` 配置，打开独立的学习工作区并调用 `/study`。

```sh
dsh plugin --profile student add ./packages/winterhuan/student
```

配置需要已提供技能、工具、会话文件系统和沙箱策略。web 配置还提供对话、图片附件和学习工作台侧栏。安装层添加 `student` Host 行和 `preset-student` 模式行，不安装任何创作包。安装或重新构建后重启配置。

DSH `0.2.2-rc.5` Headless 不选择 Web 预设列表。非 Web 配置应禁用 `preset-student`，并在创建 Agent 前通过以下配置补丁加载已安装的 Student Agent 入口：

```yaml
- id: preset-student
  disabled: true
- insert:
    - id: student-headless-capabilities
      name: '@winterhuan/dsh-student/agent'
```

配置需要提供相同的原生工具与文件系统服务。安装已启用现有 `fs-observation-policy` 行，保留单个实例。在 `agent/created` 后加载 Student 入口无法捕获该 Agent 的普通输入归属。重启配置并创建新 Agent 后，再调用 `/study`。

### 使用学习工作台

工作台采用一层功能导航，取消学生／家长切换；窄屏下入口自动换行，全部可见。切换页面保留当前题目和草稿。学习首页提供「今日推荐｜语文｜数学｜英语」。推荐结合已有档案、学校进度、家长额外限制、未完成活动、真实回答、薄弱点、到期复习及近期学科覆盖，每项说明学科、目标、理由和结束条件。选择学科只筛选推荐，不启动活动或替换当前题。已有档案无需逐科解锁；缺少教材或学校进度时先补问缺项；只有明确选择基础目标课后才使用自编例子。「开始今天的学习」通过原生对话保存安排，工作台独立读取后进入学习中。没有每日任务数档位、分钟目标或漏学补课清单。

学习中展示当前任务、一道已保存题目、配图、作答区与合适的主要操作。选项题点选，其他题输入作答。原回答和反馈持续可见，来源、帮助或日期未知时保留待核对。原生助手根据真实反馈选择接下来的讲解、检验或复习；「一起试一试」打开官方组件、课件或教学卡片。完整课堂先独立核对冻结原题与绑定，再通过受保护入口播放。「暂停」或「今天先到这里」进入今日收获，按学科展示实际尝试、待巩固、待核实和未完成内容，不重复推荐列表，也不授予掌握。「继续学习」恢复原任务、原题和草稿；完成后明确选择「还想学一点」才增加可选活动。返回首页保留当前活动。没有每日计划的已有活动同样可接续；首页可以直接查看今日收获，查看不结束活动、不创建计划。收获列出实际学习内容和待核对结果；首次明确暂停或结束时只登记原活动和真实选择，原题与草稿保留。原生消息接收与已保存证据分开处理；接收不确定时提示查看对话，不自动重发。模型错误仍显示在对话中。

各功能页展示原课堂回答、官方批改历史、有效评价、未知事实，以及带实际独立作答日的范围进度。课堂记录保留原任务查询与恢复操作。「练习批改」先列出练习单与生成、预览打印、批改入口；作业和错题上传收在可展开区域，有待核对的练习册作答或教学任务时自动展开。错题本集中提供到期筛选和复习入口，编辑与管理操作折叠；没有待核对错题时不显示空列表，习题库按需展开。「知识进度」包含概念关系、知识地图和当前所选学科的摸底；浏览其他册保留已选学习范围与当前学习段。「学习档案」先显示当前学生资料、本周小结与所选学科的掌握概览；学习证据、原作答记录和档案设置默认折叠。档案、教材与学校进度、兴趣、课堂服务和学期归档分组展开，归档操作收在设置末尾。可选表单通过应用的类型化接口保存档案、课程及学校进度。所选学科的已保存练习记录另有补充修订表单，分别修改评估、错因、作答帮助与家长确认的实际作答日期；整张练习单的实际作答日期用于未单独填写日期的回答；逐题日期与明确的待核对覆盖值保持不变。原回答与冻结题目依据始终可见。草稿按学生、学期与编辑实体保存，切换页面和无关刷新后仍保留。记录校验失败时提示在对话中核对原记录；连接失败时保留题目与草稿等待恢复，记录恢复有效后页面自动更新。保存使用当前已观察文件版本；相关冲突保留草稿并显示当前值，可明确采用当前值或保留已核对的草稿；旧学期草稿不能改变当前学期。默认练习、转录确认和归档操作向原生对话提交完整意图。纸面转录置信度与正确性、帮助分别保留；只有高置信、明确答对、已知帮助且没有不确定信息的草稿提供批量确认。待确认、到期和近期作答列表最多展示 20 条；更早记录可在对话中查询。

「学习档案」底部的「作答记录资料（可选）」默认收起，不在学习和练习页面显示历史缺项数量。无需逐条补齐；「让助手整理记录」向原生对话提交按学习段或练习卷分批检查的请求，覆盖当前学期全部已保存作答，排除已作废练习单。助手只依据原始证据或家长明确确认修正，无法核实的信息保留未知，不用评分或接收日期补作答日期。原题、原回答和已有批改保留，不新增作答或更换当前题目。「按题查看缺失信息」可展开完整数量和前20条记录，并保留逐题核对入口。

### 打开互动课

工作树中的单元课程实现采用「目录 → 当前课节完整互动课 → 后续复习小课」。在课堂记录整理真实教材版本、正文、目录和单元内学校位置；每次只生成明确选择的课节，后续课节按需开始。全单元综合课在校内学完或明确准备测验后生成。新课先保存六环节教学计划，通过 `openmaic_generate` 生成；准备完成后核对实际内容、题量和答案依据，再允许打开。

按钮只显示简短意图，原始回答保持原文；结构化执行信息保留在原生消息来源中。生成进度通过原任务查询，不调用模型；未知提交结果保留任务，不自动重试。可复用小课保存 HTML 与内容指纹，点击后直接隔离显示；外部脚本和联网不在该预览范围内。观看、生成成功和活动结束均不授予掌握。独立环境的真实服务与性能验收完成前，这些改动不替换日常远程安装。

Student 组合固定官方 OpenMAIC 0.4.0：四个工具和四个 DSH skill，可使用完整课堂、独立 simulation/game/code 组件、课件和教学卡片。Host 默认连接官方服务，Token 剩余不足 24 小时自动续登并核对相同 learner，安全读取遇到明确 401 最多续登重试一次。生成提交遇到拒绝、重定向或未知结果不会自动重发。生成及时返回结构化 job 身份，重启后继续同一活动只轮询原任务。学习文件均由 agent 编写并运行只读 CLI。[24 项方法来源清单](knowledge/skills/study/openmaic/README.zh.md)区分可复用教学方法与官网专用工作流，正文和引用按需读取。

Host 将每次网络请求（包括响应正文）限制在 `requestTimeoutMs`（默认 30 秒）内，每次授权或生成操作限制在 `operationTimeoutMs`（默认 120 秒）内；响应读取超过 8 MiB 时停止，不进入 JSON 解析。取消本地等待保留已接受的 job，不代表服务已取消。轮询地址和每次读取重定向必须保持已配置原点；原始错误及响应头不进入工具回执。

独立的已安装 Chrome 窗口通过官方登录流程核对账号后播放课堂；挑战保留同一窗口供家长登录，普通系统浏览器保持自身登录状态。

安装 Student 会启用 profile 已有的 DSH Credentials provider，包括 headless。保留已配置的存储，显式用户补丁仍优先；已保存引用优先于环境后备。Student 的 `openmaic` Host 配置默认引用 `OPEN_MAIC_USER`、`OPEN_MAIC_PASSWORD` 和 `OPEN_MAIC_ACCESS_CODE`，由受保护的 provider 解析值，不将值写入插件配置。账号授权与 job 恢复使用 provider 的私有 grant 记录。`browserProfileRoot` 可指定私有的持久化 Chrome 目录，默认使用 `DSH_HOME/student-openmaic-browser`（或 `~/.dsh/student-openmaic-browser`）。打开或继续课堂时核对过期时间；Host 释放时关闭所属 Chrome context，重启后复用该 profile。预构建包包含固定官方 Host 及其 npm 依赖，通过仅发布客户端的 Loader 行提供未修改的官方浏览器 bundle，并将工具和技能限定在 Student 模式内。安装无需构建或修改安装器策略；生成的 `lib/openmaic/source.json` 记录固定源码与依赖锁。

Student 在 Web 和 Headless 中启用 profile 已有的 `fs-observation-policy`，先于原生文件工具注册。原生覆盖要求先读取，拒绝已改变版本和并发创建；重试前重新读取并合并。Session 重启后须重新读取。Shell 命令、外部编辑和多文件迁移不受该单文件保护，须保留备份并报告冲突或部分完成。

DSH 从启动命令所在目录读取项目 `.env`，同时支持 `$DSH_HOME/.env`；切换 profile 不会自动加载另一个工作目录的 `.env`。独立验收请从包含凭据的项目目录启动，或通过 DSH 凭据设置保存引用；修改 `.env` 后重启 Host。不要把密码粘贴到对话或课程文件。

### 选择学习方式

智能学习根据现有记录选择主要活动和必要的短复习。孩子可在原生对话中换内容或提出自己的问题。家长可从「知识进度」发起摸底，或从「练习批改」发起复习。下列活动仍可通过助手使用，与每日安排分别记录。

| 学习活动 | 适合什么时候使用 | 前提 |
|---|---|---|
| 同步学习 | 按已确认的学校单元练习；明确选择基础目标课时，使用标明来源的自编例子 | 家长已确认学习档案 |
| 错题复习 | 回忆已确认的错题，或尝试相关变式 | 所选科目有已确认且到期的错题 |
| 摸底检测 | 按知识地图抽样做几道短题，找出已经会的和要再练的知识点；分轻量、常规、全面三档 | 已有学习档案；每科 14 天建议一次，可随时重做 |
| 自主探究 | 围绕孩子的问题，进行猜想、观察和解释 | 已有学习档案；在对话中说明想探究的问题 |

首次活动前，在「学习档案」确认学生资料；已有学校进度提供默认学习范围，家长可按需要调整。家长可核对并修改助手提出的概念定义、例子和依据，再确认概念；助手据此建立学习目标及有依据的前置、组成、对比、解释或因果关系。旧错题保留原 `topic`，核对后再关联目标。切换活动保留待处理题目与回答。提交后等待反馈；「暂停」保留续学位置，「今天先到这里」将未完成内容保留在今日收获中。

错题本可以打印每日小卷、练习卷和巩固卷：每日小卷 4 到 6 题，按当天学科环节出题（生字或单词、句子或口算，再挑一个反复出现的错因出变式）。练习卷覆盖当前学校单元，一张卷里可以有这个单元的几类题，题型会换开，孩子在纸上写答案。巩固卷由系统挑错题：当天或明天到期、复习阶段最低的最多 8 条，每条一道变式，已经印在还没批改的卷上的错题不会重复挑。练习单渲染为网页：家长在工作台预览整张卷，再经浏览器打印对话框选择打印机或「存储为 PDF」，Windows 同样可打印。卷面能画线段图、人民币、十位个位点子图和计数器、百数表（含九格局部窗口）、数轴、钟面（整时、半时和几时几分）、小棒、竖式格、图形比较、平面与立体图形辨认、重叠圈（和圈与集合图）、数的分与合、规律条、数墙、方格表、点子方阵、厘米尺、方向板、天平、田字格、四线格，画不出的图形用简笔画兜底，每题留一行、三行或一个方框的作答区，屏幕上的题图与打印出的题图是同一套。卷面只有题目、图和作答空间，答案依据留在学习记录中。

孩子做完后，家长在错题本展开这张卷，对照参考答案逐题点对、半对或错，答错时可以填上孩子写的答案并选错因，再保存批改；也可以把卷面照片发给助手：助手逐题保存转录草稿，家长通过聊天或可选手动表单核对确认后入库。练习卷上答错或半对的题记入该题学习目标的错题；改判为对时这条错题随之删除。每条巩固题按复习阶段变换式：先换数字、再换情境、再到说理，并保留原错因。巩固卷上的题按天计算：独立答对在任何一天都进入下一阶段，下次复习日从做对那天起算；答错或半对只回到第二天，阶段不倒退。不再用的卷可以作废，卷上的错题随后能重新出题。纸上结果不用开启计时学习段，也不发星。

若已启用 DSH 的 SenseVoice 语音输入，可用对话麦克风口述答案。转写文字先进入对话草稿，学生核对并发送后，助手按当前题目保存原回答。转写文本不能用来评价朗读或英语发音；工作台没有第二套录音控件。

### 确认学生与资料

每个工作区在格式 2 正式文件中保存一名学生的一学期。原生对话是设置与管理的默认入口；家长确认昵称、地区、年级、学期、学年、学制、兴趣和可选课程备注。未知学年等待实际确认。档案编辑保留历史学习上下文；教材与学校进度共用一次设置写入。基本档案确认后可先做基础练习，再完成校内关联。归档保留原学期身份与来源；新学期使用新身份。旧来源可读取，新的正式文件工作需先明确迁移。

逐科确认书名、出版社、版次、封面或版权页依据以及当前单元。确认教材后，再在「学习档案」设置里选择学校现在教到的地图单元：新课和摸底停在这个单元以及已经教过的单元，可以选跟上学校或先补缺，复习周不开始新目标，预习最多提前一个单元。进度只在确认后前移。校内同步要求版次已识别、课程范围匹配并记录家长确认。课程未确认时可进行明确标注的基础练习。教材改版使用独立资料 ID，先前作答保留原资料引用。官方入口和来源规则见[教材资料](knowledge/skills/study/references/materials.md)。

### 使用默认教材

二年级上册未提供某科教材时，`/study` 使用随包提供的人教社语文或北师大版数学，用户提供的教材和课页优先。无需再次上传这两本书；完成档案设置后选择“通用基础”，或在对话中说“用默认数学教材学习乘法”。尚未指定学习主题时从第一单元提供短小选择。默认教材不代表学校采用版本，也不自动填写校内进度；英语和其他年级、学期没有默认教材。

教材目录、版本依据和读取规则见[默认教材](knowledge/skills/study/references/default-textbooks.md)。课页通过 DSH 的 `read_image` 按需读取，需要支持图片的模型；文字层仅供检索定位，不能直接用于拼音、图形或竖式判分。缺少图片能力时使用用户提供或已核对的题干，或明确标注的自编基础练习。

<a id="use-the-knowledge-map"></a>
### 使用知识地图与薄弱点

插件内置一、二年级上下册的语文、数学、英语知识地图，共十二份，依据《义务教育课程标准（2022年版）》第一学段整理。语文和英语的一年级上下册、二年级上册按家长确认的教材目录列出单元和课名；数学这三册对齐沪教版五四制 2024 年相应册次目录。三科的二年级下册仍用先前的学习框架。它是学习框架，不代替学校课本和教师进度。地图里的学习目标无需家长确认即可用于出题、作答、错题归类和练习单；助手用 `study_status kind=curriculum` 读取知识点定义、例子和可考事实后出题，并在每道题上记录学习目标。十二份地图的每个知识点都有可考事实，题目不得超出这些事实。二年级上册语文整理自随包人教课页。语文一年级上册和一年级下册里，读到统编版（2024）课页并且正文清楚的知识点，已改成课文原句、生字和笔顺；《1 a o e》和《2 i u ü》仍是原来的事实。语文二年级下册仍按这一课可以核对的内容整理。英语二年级上册 Unit 1 到 Unit 4 对照家长朗读纸；该册 Unit 5 到 Unit 10、一年级上册 Unit 1 到 Unit 6 与 Unit 8 到 Unit 10、一年级下册 Unit 1 到 Unit 10 写入了读到的 2024 沪教五四制原句。一年级上册 Unit 7 只有对得上的句子改过。Starter、两册附录和二年级下册仍是话题词的意思。数学一年级上册、一年级下册和二年级上册里，读到课页或教案并且概念对得上的知识点，已改成这些页面上的算法、口诀和图形特征；没有对上的知识点仍是原来的事实。数学二年级下册这次没有改。读到概念对得上的课页或试卷后可以改这些事实。出版社和册次可以不同。试卷题目是课程佐证，新题另写，不照抄原题。

今日推荐、知识地图、薄弱点和学习档案使用同一份已确认范围内的能力进度，保留真实独立作答日、答错或依赖帮助的尝试、到期复习和待核实来源。较小范围内的掌握不能继承到扩大后的范围；尚未关联能力的历史记录仍显示为待关联。今日安排完成与长期掌握分别表达，今天结束时仍可有待巩固内容。这些状态描述已有证据，不替代学校评价。选择与结束规则见[每日安排](knowledge/skills/study/references/daily-planning.md)，地图覆盖与查询见[知识地图](knowledge/skills/study/references/knowledge-map.md)。

家长可选的摸底检测是重复进行的短摸底，其强度与每日任务量无关：每科把未探查、久未练习和已掌握超过 35 天的目标按单元轮流取样，距上次摸底满 14 天时建议再做一次，也可随时重做。强度分三档：轻量 3 题（全部选择题）、常规 6 题（默认）、全面最多 12 题（每单元至少一道说理题，并复测练习中的目标），工作台按未探查数量推荐一档；内置习题库可为抽样目标附带推荐摸底母题。摸底段里每个目标一道短题，作答必须关联学习目标；从未独立答对的目标只要答错一次就标为需要加强，今日建议随即转向针对性练习。摸底不计分、不排名，也没有时长截止。

### 学习与复习

辅导者开启一个学习段，提出简短问题，等待学生并记录真实回答与帮助程度。没有单段、休息或每日分钟限制；孩子累了可以随时停止，不扣星、不责备、不补打卡。时长是包含等待的钟表时间，停止时按实际经过时间记录。日期使用上海时区。不安装后台闹钟或屏幕锁。作答匹配、选项归一与摸底强度见[软提醒决策](https://github.com/winterhuan/dsh-creative/blob/feat%2Fstudent-native-chat/.agents/notes/implemented/bug-fix/2026-10-18-student-soft-time.zh.md)；取消时长限制见[全面改造决策](https://github.com/winterhuan/dsh-creative/blob/feat%2Fstudent-native-chat/.agents/notes/implemented/feature/2026-10-30-student-overhaul.zh.md)。

每天实际作答最多获得一颗参与星，学生复述可再得一颗。挂机、多刷题、延长学习和连续天数均不额外加星。进度报告展示证据和主题，不排名，也不当作考试成绩。

图片错题由辅导者通过 DSH 读取，保存转录和疑点，再请用户确认修正后的题干与答案依据。所有新错题确认前都处于待核对状态。确认后的第二天起算到期；独立答对在任何一天（提前也算）都使间隔依次延长到 1、7、16、35 天，同一天最多进一阶段；依赖帮助或答错只回到第二天，阶段不倒退。复习进度由全部作答记录推算，改判或补录后会重新计算。不同三天的独立答对仅作为进展证据，不等于永久掌握。家长也可通过对话录入、编辑或删除已确认错题，并把题目收入工作区习题库供后续变式参考。

可以请 `/study` 查看进度、继续到期错题或探究孩子的问题。探究围绕孩子输入的疑问，采用小型预测、观察和解释过程。可选的每日提醒仅在家长指定时间后使用 DSH 当前可用的提醒工具，本包不自动创建提醒。

## 理解实现

职责与信任边界见[学生学习子系统](https://github.com/winterhuan/dsh-creative/blob/codex%2Fstudent-openmaic-loop/docs/subsystems/student.zh.md)。在仓库根目录通过 `pnpm --filter @winterhuan/dsh-student build` 构建，通过 `pnpm --filter @winterhuan/dsh-student test` 测试。

Host 入口负责已验证工作区读取、类型化手动保存和配置。`./agent` 导出在 `student` preset 及继承它的原生子 Agent 组合内注册领域技能和工具。preset 提供任务专属 persona 和显式原生工具组合，不改变默认模式。学习模式使用文件、搜索、网页、提问、呈现和系统对应的 shell 工具，不默认挂载委派或创作生产工作流。

[配置补丁](cordis.patch.yml)加载[宿主插件](src/index.ts)。[知识地图加载器](src/curriculum.ts)读取并校验 `knowledge/curriculum/` 里的十二份地图与 `knowledge/curriculum/exercises/` 习题库，状态文件只保存目标引用。[学习状态更新器](src/learning/update/index.ts)检查课程、概念关联、奖励与复习转换，用地图校验内置目标引用，并从作答、纸上结果和错题阶段推导掌握状态、薄弱点与每日建议；[状态定义](src/schema.ts)校验模型输入和持久化数据，并迁移去掉已删除的时长字段。新增集合有默认空值，旧档案读取时不猜测概念关联。面板和工具共用持久化的题目、已提交答案、提示请求、纸上结果与工作区习题；辅导评分必须对应已保存题目和学生原始回答。示范保留在教学内容里。已发布练习单冻结每题的内容、目标与历史背景；来源错题更改或删除不影响练习单使用，替换卷面需要新身份。练习册照片核对后保留原答案和结果，不把接收时间当成实际作答日期。原生工具参数由同一输入定义投影生成。DSH 的常规工具日志记录调用和结果。

[正式文件接口](src/files/index.ts)通过 `./files` 导出，让应用读取、类型化手动保存与只读 Node 消费者共用严格定义和业务校验。格式 2 在 `.study/settings.json` 保存学期设置，在 `.study/blocks/<blockId>.json` 为每个学习段保存一份文件，在 `.study/worksheets/<worksheetId>.json` 为每张练习单保存一份文件，在 `.study/collections.json` 保存其余有上限的集合；每日安排存入 `.study/plans/YYYY-MM-DD.json`；OpenMAIC 保留独立校验的 `.study/openmaic-lessons.json`。读取检查目录成员与实际文件版本，最多尝试三次。已校验文件、备份及查询缓存归应用 Host 所有，并在其释放时清空；只读适配器保留各自缓存。证据与工作台缓存归各自的投影状态所有。无效实体暂停相关保存。无关文件无效时，设置与教材查询明确返回部分结果；证据不完整时暂停小结投影。应用在 `.study/backups/` 为每个实体保留最多三个已观察的有效版本，总计不超过 128 份备份和 32 MiB 源字节。同一个 Host 所有者按设置文件的实际目标串行执行完整备份保留操作；没有该所有者的自定义文件适配器仅保证顺序保留。备份发现、读取、清理与写入失败分别报告，不阻止有效业务数据的读取或保存。恢复描述要求明确选择并保留无效原件。工作台通过注册时声明的 store 在渲染前恢复草稿，组件使用普通回调调用宿主；手动保存检查学期身份、编辑字段基线和当前文件版本。档案保存将选定编辑字段与当前未编辑值合并；教材与学校进度共用一次设置写入。校验原始字节的 v1 迁移与归档描述逐项提供输出和缺失来源事实，不写入或修复业务文件。正式文件每份最多 8 MiB，活动学期总计最多 32 MiB，包含最多 5,000 个学习段、500 张练习单与 128 个归档学期目录。每日计划最多 1,000 份，每份 1 MiB，并计入同一总量上限。日常读取包含今天、近期实际学习日、续学所属计划及直接原始引用，历史查询指定日期。计划元数据无效时保留原学习记录并暂停相关推进。计划只保存稳定任务、理由、结束条件和明确选择；回答与掌握仍由原始证据提供。读取不保存预览，午夜不启动新活动。旧 `.study/state.json` 可读取且不改变原字节；评分时间、接收时间与默认独立作答不会成为已核实的学习证据。已验证迁移备份标明所需输出；缺少文件时工作区保持 migration-incomplete，完成前不提供当前事实。

### 演练恢复

构建后，使用已安装的 DSH `0.2.2-rc.5` 可执行文件和仓库外证据目录运行真实原生工具恢复测试：

```sh
DSH_BIN=/absolute/path/to/dsh STUDENT_EVIDENCE_DIR=/path/to/evidence pnpm run test:recovery
```

测试使用隔离临时 Home、Agents 和 Documents 目录，再等待子进程清理。它通过真实原生 write/edit、构建 CLI 和独立消费方覆盖合成 v1 来源保留、中断迁移及来源变化拒绝、有界已观察备份、明确恢复、部分归档、新学期拒绝与重启。它不在独立恢复工作区运行旧插件，也不建立浏览器、固定 Git、真实教学、OCR、课堂或物理打印验收。

[官方反馈读取器](src/openmaic/feedback.ts)在播放前冻结题面，再读取已授权原 learner 的 sessions/records。agent 将返回的归属、题目、不可变提交与官方批改历史写入原学习文件，运行打包只读 CLI；Student 独立消费接受保存内容后，agent 才推进课堂检查点。明确数值等价保留原官方评分与有效评分。无法自动比较的文字选项保持待核对，家长的明确判据更正须匹配真实消费过的原生输入、原回答及题面哈希；更正保留官方历史，不确认作答日期或独立性。仅批改、提交冲突与跨 session 关联不明的记录，以完整原事件保存在所属 block 的 pendingOpenmaic 数组。完整保存的待核对事实可以确认已读取，但不授予掌握；不完整或超限读取保留原检查点。未知日期与帮助保持未知。模型自写的来源或确认标记不认证证据。详见[反馈流程](knowledge/skills/study/references/openmaic-feedback.md)。

构建后运行 `node packages/winterhuan/student/tests/openmaic-feedback-native.e2e.mjs`，验证确定性 HTTP 来源、原生作者、CLI、独立消费与重启；`DSH_BIN` 指定已安装可执行文件，`STUDENT_EVIDENCE_DIR` 指定仓库外证据目录。可选 `STUDENT_OPENMAIC_ONLINE_DIR` 保存私有原 job/auth/capture 元数据，用于真实线上来源验收；证据目录须保持私有。该模式保留既有生成归属并核验真实来源导入，完整原生建课另行验收。

### 校验原生文件编辑

构建本仓库后，运行随包发布的同一可执行文件：

```sh
node packages/winterhuan/student/lib/cli.js --help
node packages/winterhuan/student/lib/cli.js schema term-settings
node packages/winterhuan/student/lib/cli.js example figure
node packages/winterhuan/student/lib/cli.js validate --workspace /path/to/workspace
```

安装后使用 `<study 技能 Base directory>/../../../lib/cli.js`；`./cli` 导出与 `study-validate` bin 指向同一文件。DSH Git 安装不承诺全局 PATH 命令。校验读取正式文件与完整独立课程日志，保留字节/修订，不创建备份或修复。退出 0 指明观察到的 kind、身份和版本；非零 JSON 指明路径、字段、规则和修正方式。校验输出最多 32 KiB，并明确遗漏。schema/example 从源定义生成完整资源；跨文件和来源事实检查仍由 CLI 执行。CLI 未独立匹配 Host 接收版本时，原生作答日期保持未知。部分操作和明确恢复见[编辑参考](knowledge/skills/study/references/files.md)。

能力与母题查询从[随包学习目录](knowledge/curriculum/capabilities/catalog.json)读取判据、先修和来源，与个人记录分开。新能力题保存母题及实际检验范围；旧课程 ID 保留历史去向。等价工作区母题解析为同一有效题型。核对后的错题声明可保存 `capability`，按目标、母题与等价范围归并旧实例，同时保留冻结原题；这项分类不授予作答证据。已全部评分的练习单可在原位保存 `archivedAt`；日常列表收起它们，按练习单 ID 仍可查询，原作答证据继续保留。学期设置的稳定 `learnerId` 跨学期延续；旧格式2缺少身份时需核对。归档证据引用指向同一学生的原学期、实体与回答，不复制答案。只读迁移描述要求确认学生身份、逐文件原字节备份和完整课堂日志读取。`describeKnowledgeMigration` 覆盖活动及归档格式2学期，报告部分写入与冲突，未绑定旧课堂保留待核对；原题、回答与评分声明保留，未知日期、帮助和答案依据不授予进度。CLI 按需资源包括 `capability-goal`、`question-family`、`knowledge-extension`；详见[编辑参考](knowledge/skills/study/references/files.md)。

[共享继续查询](src/learning/mastery.ts)按当前题、待评价、来源核验、当前或先修缺口、短复习及已确认新学给出唯一下一步与可用操作。学习段保留检验／复习的成员、已进入母题、已呈现实例和结束事实：三道新检验实例或两个已进入复习母题占用额度，错误、跳过、未知日期和帮助不返还。切换学习段、跨午夜与重启保留额度；自动复习在同一学习日累计最多进入两个母题。已结束轮次可在后续学习日重新安排有界复习；未结束轮次保留消耗。同日学习新目标不重置当日额度，额外复习需明确请求。已有学校进度和历史范围直接参与推荐；可选 `learningScopes` 记录家长额外限制并优先于该科默认建议。升级沿用原确认，不补写新确认；新目标无需预造题。有学校课程时遵守当前单元、补已教单元和复习周限制。缺少适用年级目录或没有可学目标时明确暂停，并给出休息／恢复选择。同一冻结实例揭示答案或提供示范后，重答不获独立信用。明确原归档引用提供范围内掌握基线和独立重放的复习日期、阶段；缺失或不兼容原档不授予进度。首次掌握与恢复掌握跨学期分别保留。下一官方教学需求包含有界的已保存反馈与复习发现，并明确报告遗漏；大词表请求只教学列出的子集。

内置目标的新题默认使用保存的历史档案年级与学期；跨册时必须由 `context.scope` 明确选择匹配的知识地图，浏览本身不授予范围。只有摸底学习段可记录强度，摸底题不带教学阶段。复习题绑定同科的已确认错题或明确范围的已学能力。准备的错题巩固题须更换原题面；练习册记录保留原题面。旧题保留未核实事实，已观察使用内容在来源错题更改或删除后保留冻结绑定。

[Student Remote](src/remote-service.ts)为已注册的 DSH 主会话提供生成的类型化查询、显式手动保存与提交检查。Gateway 在每次调用前检查会话权限；缺失、已关闭和子 Agent 会被拒绝，且不触发激活。提交检查分别报告原生消息接纳、已保存原答与有效的已保存评分，绝不重发输入。手动保存使用已观察的学期、版本和编辑字段基线；设置明确提供 `editedProfileFields`。Host 配置默认 `refreshIntervalMs: 3000`、`maxWireBytes: 1048576`，限制完整请求与响应的 JSON 大小，包含 watch/manual/inspection 包装；超大的手动请求在保存前拒绝。[客户端资源提供者](src/client/resource.ts)通过原生重连跟踪 `dsh-resource://student/session/<encoded-id>?query=<encoded-JSON>`，在失败时报告错误并将之前的值标记为过期状态，等待流关闭后才撤销命名空间。

[原生来源读取器](src/transport.ts)观察调用方会话与明确引用的原始主会话。历史读取须核对相同规范工作区、当前调用权限，以及原消费 Student intention 或 Host 接收捕获中的 learner/term/block/question 归属。普通输入框和 Headless 的空闲输入在接纳前冻结独立读取的原归属、题面与文件版本，证据接受前再核对精确消费和未变版本。Headless profile 必须在创建 Agent 前加载 Student 的 `/agent` 能力；DSH Headless 不选择 Web preset。`dsh-session` 使用 peer 依赖，确保捕获记录写入运行中的同一 Session 实例。活动回合中排队或缺少有效捕获的输入保持归属未知。系统同步、工具和技能消息不提供孩子回答或作答日；原来源缺失或不匹配时保留未知日期。最多读取八个原会话、32 MiB 物理历史和 32 MiB 总重放；公共 provider 支持正常压缩历史，不要求可选 eventCount。每次完整原始重放上限为 100,000 事件与 16 MiB；原生返回视图上限为 32 KiB、20 个已消费输入、20 个接收状态、每输入 2,000 字符及八个附件引用，明确报告遗漏数量。不完整或不支持的历史不提供可信接收事实。接收版本匹配包含附件的完整来源与内容，后续消费、文件写入与批改不产生作答接收时间。

练习单由[客户端试卷视图](src/client/worksheet-view.tsx)渲染，与屏上题图共用同一套 SVG 图形；打印走浏览器打印对话框（可选择打印机或存储为 PDF），Host 不生成 PDF，也不调用系统打印队列。客户端通过原生会话队列提交辅导请求，不替换输入框草稿。明确继续已授权课堂时，每课堂最多一个待处理系统同步意图；浏览页面和窗口获得焦点不唤醒模型。暂停在原生取消前撤销所属待执行同步。接纳消息不等于反馈保存，完成或取消后可在下次明确触发时重试。

默认教材资源位于技能的 `textbooks/`，随 `knowledge` 打包。目录、逐页图片和未校对文字由[教材准备脚本](scripts/prepare-textbooks.py)从两份已核对的 PDF 生成；脚本使用 PyMuPDF 1.28.2 并在写入前校验源文件哈希。运行时使用原生文件和图片工具，无需 Python、PDF 解析器或原始下载路径。教材选择由技能指引，不自动修改学习状态；默认教材作答的页码和依据保存在 `answerEvidence`。

## 模型体验

### 学习指引与记录

#### 模型看到的内容

Student 模式注册 `study_status`、`openmaic_feedback` 和四个官方 OpenMAIC 工具，以及 study 和四个官方 DSH skill。[提示词快照](../../../tests/fixtures/student-persona.txt)记录前缀；标准与其他模式不包含这些工具与技能。官方编写契约和选中方法资源按需加载。Host 账号凭据与浏览器授权不进入模型参数、工具回执或学习文件。agent 通过原生文件工具完成学习写入并运行随包只读 CLI，区分消息接收、回答保存和有效评价保存。

#### Token 影响

技能正文和参考按需加载，启用时提供两个只读 Student 工具定义；每次请求也包含原生工具的成本。集合查询每页返回 20 条及下一页偏移。不加载整本教材。两个隔离的 DSH 0.2.2-rc.5 首次请求使用同一空工作区、输入及类似 Web 的 preset 组合，固定密度估算测得基线包为 8,765 tokens，官方组合为 10,808，增加 2,043（23.3%），包含消息和工具定义。独立 Headless 入口的能力在 Agent 创建前组合，其实际调用路径由原生测试覆盖。24 份官方方法正文仍按需加载。请求未调用付费模型或写学习事实；该估算不衡量提供方计费、整课成本、教学质量或 KV Cache 性能。

#### KV Cache 影响

插件使用常规 DSH 技能与工具历史，不改写已有消息，也不创建其他模型会话。

## 已知限制与待办

<a id="known-limitations-and-deferred-work"></a>

- 数学一年级上下册和二年级上册的单元与知识点对齐沪教版五四制 2024 年目录，仍不是逐页课本。语文和英语的这三册按家长确认的目录列出课文和栏目，也不是逐页课本。三科二年级下册仍用先前的学习框架，可能与学校课本不同。掌握状态只统计带学习目标的记录，旧作答没有目标就不进入薄弱点分析。摸底一次最多探查六个目标，取样跨单元但不是全面测评；摸底题由模型按目标出题，有可考事实时答案不得超出这些事实，题目质量仍需家长留意。
- 插件不认证家长身份、不测量注意力、不保证 AI 答案，也不提供完整的上海课程库。确认记录用户陈述，来源分类本身不能证明正确。实际教材、学校进度和争议答案仍需人工核对。
- 图片录入依赖支持视觉的 DSH 模型与可读附件。本包没有独立 OCR 服务、教材下载器或自动提醒。图片路径引用提供的附件，不将图片字节复制进状态文件。语音输入依赖另行启用的 DSH Bundle，转写不验证发音。
- 打印经浏览器打印对话框完成，可选实体打印机或「存储为 PDF」；实际纸张输出与浏览器打印状态由家长自行核对，本包不提供打印队列回执。
- 记录的学习操作没有时长限制；插件仍不能锁定操作系统或任意聊天。应用保存和原生 write/edit 工具检查已观察版本；shell、外部写入和多文件事务不受该单文件保护约束。已观察备份不能恢复未曾读取就被覆盖的历史，迁移与归档逐份写入文件。
- 状态保存在本地，但辅导用到的片段和图片会传给配置的模型提供方。插件不是离线或加密的学习资料库。原生工具和文件系统测试不能证明真实模型的识图准确率或教学效果。

- 单元课在生成前独立审题，生成后比对原题并复核全部场景；语病、错误事实、歧义、不确定或缺失审查均禁止播放。审查凭证绑定原任务与材料指纹，重复打开不调用模型。官方生成仍可能改写题目，改写时拒绝并需显式重新制作。该流程尚未通过完整真实学习与性能发布门槛。
- 完整课堂使用外部 OpenMAIC 服务。浏览器播放需要已安装 Google Chrome，登录挑战由家长在同一独立窗口恢复。课程历史跨学期保留；官网专用场景编辑、导入与约束执行只纳入清单，四个 DSH 工具没有提供这些执行能力。
- 转录、变式题和每日小卷由模型生成；卷面照片先保存为转录草稿，家长通过聊天或可选手动表单确认后才进入记录和复习，纸面练习仍是主要学习形式。
